Respaldo · exportar / importar

El archivo JSON incluye todos los casos (con imágenes y documentos) y esta configuración. Sirve para hacer copias de seguridad o pasar los datos a otro navegador o equipo. Al importar, los casos con el mismo id se actualizan y el resto se agrega.

Almacenamiento

Los datos viven en el localStorage de este navegador (límite aproximado de 5 MB). Exportá a JSON periódicamente como respaldo.
